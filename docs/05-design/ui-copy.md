# UI copy (voice & tone)

## Voice

Warm, direct, Indian-English. Short sentences. No jargon. "Aap" implied (imperative), not "aapko".

## Glossary (fixed words)

| Use | Don't use |
| --- | --- |
| cart | bag |
| size | sizing variant |
| order number | tracking id |
| Free shipping | Free delivery charges |
| Sold out | Out of stock (badge) |

## Key strings

| Context | Copy |
| --- | --- |
| Add CTA | `Add to cart` |
| Out of stock | `Sold out` |
| Size prompt | `Select a size` |
| Cart empty | `Your cart is empty.` |
| Checkout CTA | `Place order` |
| COD blocked | `COD available up to Rs. 3,500. Please choose prepaid.` |
| Order placed | `Order placed! We'll WhatsApp you the tracking details.` |
| Payment pending | `Payment pending — pay now to confirm your order.` |
| 404 | `This page took a different route.` |
| Search empty | `No matches for "{q}". Try "anarkali" or "saree".` |
| Support | `WhatsApp us: ` |
| Newsletter | `Join the list — new drops, early access.` |

## Errors

- Validation: field ke neeche, specific — `Pincode 6 digits ka hona chahiye` (English UI: `Enter a 6-digit pincode`).
- Network: `Something went wrong. Please try again — your order was not placed.`

## Formatting

- Price: `Rs. 3,499` (no decimals), MRP strike, `50% OFF` pill.
- Dates: `24 Oct 2026`.
- Phone: `` (no +91 in UI, `tel:` link me +91).
