# Glossary

| Term | Matlab |
| --- | --- |
| **Handle** | Product/collection ka URL slug, e.g. `tridha-fendy-silk-blush-pink-anarkali-premium-suit-set` |
| **Paise** | Money ka storage unit. Rs. 2,999 = `299900`. Float kabhi nahi. |
| **MRP / compareAtPrice** | Strike-through price. Discount % isi se nikalta hai. |
| **Variant** | Product + size (+ colour) ka specific combination |
| **Collection** | Curated group (party-wear-gown, new-arrivals, sale…) — Shopify terminology se same |
| **COD** | Cash on delivery. Rs. 3,500 se upar allowed nahi, Rs. 50 fee |
| **Prepaid** | UPI / card / netbanking — gateway se pay |
| **Idempotency-Key** | Header jo same request dobara aane par naya order banne se rokta hai |
| **Webhook** | Provider ka server-to-server callback (payment.paid) |
| **AWB** | Courier ka tracking number |
| **DPDP** | Digital Personal Data Protection Act, 2023 |
| **GSTIN** | GST registration number, invoice par |
| **HSN** | Product tax classification code |
| **RBAC** | Role based access control (owner / catalog / dispatch) |
| **Prepaid vs COD fee** | COD par Rs. 50 handling, refundable nahi (change of mind) |
