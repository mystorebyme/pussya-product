# Vision

**Noor Ethnic Wear** designer ethnic wear (anarkali suits, lehenga choli, printed suit sets) bechta hai,
mostly Instagram/WhatsApp se. Website ka kaam sirf "brochure" nahi hai — customer ko wahi experience
dena hai jo ek bade brand par milta hai, bina brand ki pehchaan khoye.

## Ek line me

> Har Noor customer ko 30 second me woh suit mil jaye jo use chahiye, aur usse checkout karna
> WhatsApp par message bhejne se aasan lage.

## Success kya hai (6 mahine)

| Metric | Target |
| --- | --- |
| Catalogue coverage | 100% live styles (287 products) — title, price, MRP, fabric, sizes |
| Mobile LCP (4G) | < 2.5s product listing par |
| Checkout completion | 60% se zyada (cart → order) |
| COD orders | Har order < Rs. 3,500 par available |
| Admin ka daily kaam | Order status 2 click me, price 1 field me |
| Support load | "Order kahan hai" wale 60% messages self-serve ho jayein |

## Principles

1. **Original design** — kisi aur site ko copy nahi karna. Reference se sirf pattern seekhna hai.
2. **Fast by default** — catalogue static, images CDN se, JS kam.
3. **Paisa integer paise me** — rounding bug se order amount mismatch kabhi nahi.
4. **Trust visible** — COD, 7 day replacement, real policies, real phone number.
5. **Har change traceable** — audit log + docs update, warna 3 mahine baad koi nahi jaanta kyun tha.
