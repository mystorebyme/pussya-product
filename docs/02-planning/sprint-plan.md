# Sprint plan (1 week sprints)

| Sprint | Goal | Deliverables | Demo |
| --- | --- | --- | --- |
| S0 | Foundation | Monorepo, docs, skills, CI, 287-product catalogue | `npm run dev` par home live |
| S1 | Browse | Home, collections, PDP, search, mobile nav | Product dhoondh kar PDP tak |
| S2 | Buy | Cart, checkout, order API, order page | COD order end-to-end |
| S3 | Operate | Admin login, dashboard, orders, products, settings | Owner order status badalta hai |
| S4 | Payments | Razorpay link, webhook, payment states | Test webhook se paid |
| S5 | Polish & launch | SEO, perf, UAT fixes, deploy, monitoring | Go-live |

## Ceremonies

- Daily 10 min standup (async message bhi chalega)
- Sprint start: scope lock + acceptance criteria
- Sprint end: demo + `PROGRESS.md` update + retros (1 improvement)

## Definition of done (har task)

1. Code + typecheck + lint pass.
2. Mobile par dekha gaya (360px).
3. Empty/error state handle.
4. Docs ya skill update (agar behaviour badla).
5. PR me screenshot ya curl proof.
