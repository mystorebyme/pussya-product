# Competitor analysis

| Store | Strength | Gap jo hum bharte hain |
| --- | --- | --- |
| Noor (Shopify, current) | Real catalogue, brand trust, WhatsApp support | Slow pages, product images hotlink slow, no self-serve tracking |
| Fabindia / Global Desi | Trust, size guide, returns clarity | Premium pricing, less festive-heavy |
| Libas / Indya | Fast catalogue, filters, COD clarity | Big catalogue overwhelm, generic design |
| Instagram sellers | Personal touch, fast replies | No catalogue search, no order record, price confusion |

## Kya hum better karte hain

1. **Catalogue = 287 styles, single source** — price mismatch nahi (server-side recompute).
2. **Speed** — static pages, CDN images, no DB round-trip on browse.
3. **COD rules clear** — limit + fee form par hi dikhta hai, surprise nahi.
4. **Order tracking** — order number se status, WhatsApp dependency kam.
5. **Admin** — owner mobile se status/price change kar sakta hai, audit trail ke saath.

## Risk from competitors

- Libas/Indya ads se traffic — hum SEO (sitemap + PDP schema) aur Instagram se aayenge.
- Price war — hum fabric/styling story aur 7-day replacement par focus karenge, discount race me nahi.
